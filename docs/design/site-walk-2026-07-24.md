# GDX Dispatch — Full Site Walk (2026-07-24, v1.25.0)

Systematic click-through of the whole app: every nav item, every button, every
interactive control — recording what reacts and what's broken/empty/surprising.

**Surface:** the public demo (https://gdxdispatch.com) running the just-deployed
**v1.25.0**. Chosen because it's an isolated DB with all outbound integrations
neutered and a nightly re-seed — safe to click *everything*, including
destructive buttons, without touching real customer data or sending anything.
Driven with a real headed browser as the **owner** (`demo@gdxdispatch.com`);
mobile/tech + dispatcher roles walked separately.

**Legend:** ✅ works · ⚠️ works-but-rough · 🐛 broken · ❓ empty/not-configured
(demo) · 💤 nav-hidden (module gated off on demo, checked by direct URL) ·
📝 note.

**Method:** for each page — snapshot to enumerate every interactive element,
click each meaningful control, record the reaction. Destructive actions are
exercised (demo resets nightly). Integration-gated pages hidden from the demo
nav are reached by direct URL and their connect/empty state recorded.

## Cross-cutting issues (rolled up)

**Headline: the app is in excellent shape.** ~90 routes walked across owner,
technician, and dispatcher roles on the live v1.25.0 demo — **every page rendered
with zero JavaScript/render errors**, every list/create/filter/tab control reacted,
role-based permission gating held, and a full customer CRUD write succeeded
end-to-end. The v1.25.0 deploy is confirmed healthy from inside the app (version
footer + `/admin-ops` show v1.25.0; `/admin/database` reports "At head, ORM matches
the database" — migrations 037/038 applied cleanly). The Tier-9/10/11 work is live
and correct (QB sync chips, "Disconnected" QB state, dark-mode-fixed views,
derived Partial/Void billing tabs, revived audit log, Tier-6 expense workflow).

**Findings (all minor — no broken pages, no dead buttons):**

1. 🐛 **~15-minute session expiry with no silent refresh / no re-login redirect.**
   Reproduced twice: after ~15 min the access token expires, global calls
   (`/settings/modules`, `/session-policy`, `/branding`, `/users/me/permissions`,
   `/notifications/count`) 401, and the current page's data silently fails to
   load — the user is not bounced to login or refreshed. On the demo this just
   means an explorer hits dead data mid-session; on prod it's the same UX papercut
   for any session left open ~15 min. Worth confirming whether a refresh-token flow
   exists and, if so, why it isn't kicking in.
2. 🐛 **Dashboard makes an admin-only `/api/audit/logs` request for non-admin roles.**
   As the dispatcher, the dashboard load fires that call → **403 "Insufficient role"**
   logged to the console every time. Gate the call by permission so non-admins
   don't trigger a guaranteed-failed request.
3. 🐛 **Tour-start returns 409 to the console on every owner dashboard load**
   (`POST /api/me/tours/owner-getting-started/start` → 409 "already started").
   Make it idempotent (200/204) so it stops logging a red console error.
4. 📝 **Stale "DispatchApp" product name** in Help content ("Welcome to DispatchApp")
   — the app is branded "GDX Dispatch". Same residue class fixed in the Tier-9
   install-sheet footer; a few strings remain.
5. 📝 **AI Assistant is a non-functional shell on the demo** ("AI Assistant" + Submit,
   no input/response) because the demo neuters the LLM key — expected, but verify
   it's functional on prod.
6. 📝 **No success toast on customer create** — the new row appears and the count
   increments, but there's no confirmation toast (other flows do toast). Small
   consistency gap.
7. 📝 **Vendor Statements button reads "Upload Midwest PDF"** — a vendor-specific
   label baked into a generic action; reads oddly for a shop that isn't "Midwest".
8. 📝 **Settings password field** isn't wrapped in a `<form>` and lacks
   `autocomplete` attributes (browser DOM hints — minor a11y/password-manager nit).

**Positives worth calling out:** global command-palette search (categorized live
results), the 5-step onboarding tour, sidebar module-filter + favorites + collapse,
per-record QB sync chips, honest "data not yet captured" dashboard metrics (no fake
numbers), graceful "not connected" empty states for every unconfigured integration
(Outlook, Google Maps, QuickBooks, Phone.com), and clean AccessDenied pages that
name the exact missing permission.
