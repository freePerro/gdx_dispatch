## ⚠️ DO NOT DEPLOY THIS RELEASE

Migration `056` in this tag contains an unsafe tax-rate backfill. A dry run against a real production book (326 invoices) showed it heals 111 rows correctly but writes a **nonsense tax rate** onto 71 others (0.39%, 2.27%, 3.84%) — the derived quotient is invalid wherever the stored tax was computed against a different base than the current taxable line sum.

A wrong rate is worse than the frozen tax it replaces: it silently re-prices every future line edit.

**Superseded by v1.41.1** — deploy that instead. PR #282 anchored the backfill to the tenant configured rate. Every other change in this tag is sound.
