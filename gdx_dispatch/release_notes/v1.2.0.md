## Highlights

### 🧩 Custom Catalogs platform (ADR-015) — #46
The catalog system is now industry-agnostic and extensible, in three layers:

- **No-code custom catalog types.** Create a catalog of type **Custom…** and define your own fields (Text, Number, Currency, Yes/No, Dropdown, Date) right in the New Catalog dialog — no code, migration, or deploy. Stored as data (`custom_catalogs.field_schema` + `custom_catalog_items.attributes`).
- **Pluggable pricing strategies.** Each catalog has a pricing strategy applied when an item is saved with a blank price: **Manual** (default, unchanged behavior), **Margin 50%**, **Markup 50%**, **Keystone (2×)**. Applied consistently across the Add form and CSV/JSON import.
- **Catalog Packs.** Installable plugins (on the ADR-013 plugin-host) that contribute whole verticals — catalog types **and** pricing — as data. Picking a pack type copies its fields + pricing onto the catalog, so a pack ships an entire industry's catalog without running code in the core app at pricing time. Reference pack included: **HVAC** (`gdx-plugin-hvac`).
- Migrations `005` (field_schema/attributes) and `006` (pricing_strategy/pricing_config), guarded for fresh-DB boots. Docs: `docs/CUSTOM_CATALOGS.md`, `docs/decisions/ADR-015-…`.

### 📋 Estimates — line-item reorder — #47
Move estimate line items **up/down** with per-row controls. Order persists via the existing `sort_order` column (no migration).

### 🔐 RBAC & roles
- **Permission-driven nav visibility + canonical role names** (#42) — the sidebar now shows what a user's permissions allow; role names are canonicalized.
- **Frontend role checks routed through canonical helpers** (#43).
- **Local-auth + admin read fixes** (#44) — keep an admin escape hatch when permissions are empty; admin update-check is read-only.

### 🛠️ Notable
- Known pre-existing mypy typing noise (SQLAlchemy/Decimal) tracked in #48 — not introduced by this release.
