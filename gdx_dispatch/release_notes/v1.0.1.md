Patch release on top of v1.0.0.

**Fixes**
- **Error visibility:** admins now see permission-denied (HTTP 403) errors in the Server Logs page; repaired the error sink, which had been silently dropping every error that carried a tenant_id (a `tenant_context()` arity regression from the single-tenant cleanup). Same bug fixed in 4 module services.
- **Schema drift:** repaired queries that 500'd against tables/columns removed in the single-tenant cleanup — mobile checklist endpoints (`/my-jobs/{id}`, `/jobs/{id}/checklist`), complete-job parts count, job arrival notes, campaign-send audit fallback, and AI-usage stats (timestamptz date bucketing).
- Corrected three ORM table names that had a stray `_router` suffix (`checklists`, `checklist_items`, `checklist_templates`). These tables are created/repaired automatically on boot via `create_all` — no manual migration needed.

**Cleanup**
- Removed two unused feature-flag subsystems (model, routers, templates, Vue view + nav). Net −2095 lines.

All CI checks (incl. full test suite) green.
