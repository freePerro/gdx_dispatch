# agent_ownership.txt — which project subagent owns which source file.
#
# One rule per line:   <fnmatch glob, repo-relative posix path>   <owner>
# `*` matches across `/` (fnmatch semantics, not gitignore). LAST MATCH WINS,
# so list the broad rule first and the exception after it. An owner is the
# stem of a checked-in agent file: `.claude/agents/<owner>.md`.
#
# Read by gdx_dispatch/tools/agent_ownership_scan.py and gated by
# gdx_dispatch/tests/test_agent_ownership.py: every source file under the
# covered roots must resolve to an owner, every rule must still match a file,
# every owner must have an agent file and every agent file must own something.
# Adding a router, view, module or composable without a line here is red.
#
# Deliberately NO catch-all like `gdx_dispatch/core/*.py`: a new file has to be
# claimed on purpose, or the guard could never tell you it was forgotten.
#
# Decided 2026-09-24; rationale and rejected shapes in
# domain-agents-plan under docs/design/.
